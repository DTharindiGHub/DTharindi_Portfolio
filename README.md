# Personal Portfolio Website

Welcome to my personal portfolio! This website showcases my background, education, technical skills, projects, and experience in the Information Technology field.

## 🌐 About the Project

This portfolio was developed to present my technical abilities, academic background, and software development projects in a professional and organized way. It also provides an easy way to learn more about my work and career interests.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive features

## 💻 Featured Projects

- **Inventory and Shop Management System** – A web-based system for managing products, stock, sales, invoices, and warranty claims.
- **Curtain Delivery Website** – An online platform for browsing curtains and managing customer orders.
- **Bus Reservation System** – A web application for bus reservations and booking management.
- **Visit Sri Lanka Tourism Website** – A website showcasing Sri Lanka as a travel destination.
- **Student Management System** – A database application developed using Microsoft Access.

## ✨ Features

- Personal introduction and profile
- Education and technical skills
- Project portfolio
- Work experience
- Contact information
- Responsive and user-friendly design

## 🚀 Getting Started

To view the portfolio locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
